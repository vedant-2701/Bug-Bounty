# notes_generation_prompt.md

## Purpose

Use this prompt after completing a topic.

---

I have completed this topic.

Generate revision notes following `obsidian_notes.md` (including the frontmatter block).

Additionally:

* Update the topic's status in its curriculum track file and the curriculum's `00-index.md` (the dependency tracker — there is no separate global tracker).
* Set the `next-review` field per the confidence-scoring rule in `assessment_framework.md`.
* Identify any remaining knowledge gaps.
* List related topics that should be learned next, across any of the three curricula.
* Recommend external practice that complements this topic.
* Highlight important interview points.
* Include secure engineering considerations.
* Include offensive security considerations.
* Include backend implementation insights.
* Include common mistakes developers and security testers make.

The notes should serve as revision material, not as a replacement for the original learning resource.
